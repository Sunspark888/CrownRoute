# 代码与研究数据的使用范围

本仓库存放 CrownRoute 的项目实现、配置和合成示例。读者可以在自有图块、按实例标注的弱框及相应模型环境上检查监督构建流程。复现论文的完整数值还需要相同的影像、标注、训练成员和模型权重。

## 第三方组件

| 组件 | 本仓库的用途 | 上游来源 |
| --- | --- | --- |
| Ultralytics FastSAM-s | 可选候选生成器。使用者提供本地权重。CPU 演示读取合成候选。 | [Ultralytics 许可](https://github.com/ultralytics/ultralytics/blob/main/LICENSE) · [FastSAM 项目](https://github.com/CASIA-LMC-Lab/FastSAM) |
| PyTorch、TorchVision | Mask R-CNN 学生及其预训练初始化。 | [PyTorch 许可](https://github.com/pytorch/pytorch/blob/main/LICENSE) · [TorchVision 许可](https://github.com/pytorch/vision/blob/main/LICENSE) |
| pycocotools、Pillow | 读取 COCO 标注、计算验证指标及加载图像。 | [COCO API](https://github.com/cocodataset/cocoapi) · [Pillow 许可](https://github.com/python-pillow/Pillow/blob/main/LICENSE) |
| OpenCV、NumPy | 图像、二值掩码和数组运算。 | [OpenCV 许可](https://github.com/opencv/opencv/blob/4.x/LICENSE) · [NumPy 许可](https://github.com/numpy/numpy/blob/main/LICENSE.txt) |

各项上游实现和模型权重由其提供方分别发布。Ultralytics 与 FastSAM 的上游代码列有 AGPL-3.0。作者应在公开前复核实际使用版本、代码权属和依赖许可，决定自有代码的许可方案。当前私有审阅版本未授予开源许可证。

学生损失函数使用 TorchVision 的 RoI 掩码投影接口，并沿用其目标提取结构。仓库随附 [TorchVision 的 BSD 3-Clause 许可声明](TORCHVISION-LICENSE.txt)。

研究数据由作者另行管理。仓库不分发原始航片、真实标注、训练掩码、运行权重或预测文件。项目代码的许可不授予对研究数据的使用权。
